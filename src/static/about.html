Probability Step Chart for Excel

Converts a discrete probability distribution (an outcome column and a probability column) into the duplicated X/Y coordinates of its cumulative distribution function (CDF), draws it as an XY scatter chart with straight lines, compares several distributions on the same axes, and tests first- and second-order stochastic dominance.

How to use

  1. Select a two-column range: outcomes in the first column, probabilities in the second (headers optional).
  2. Open Home > Step Chart and choose Use selection.
  3. Check the preview, pick an output location and choose Generate CDF coordinates.
  4. Repeat with other ranges to compare distributions on the same chart; use the Analysis tab for stochastic dominance.

Privacy

The add-in runs entirely inside Excel. It reads only the ranges you select, writes only the tables, charts and analysis sheets you ask for, and stores its settings inside the workbook. It sends no workbook data to any server and uses no cookies, analytics or tracking.
